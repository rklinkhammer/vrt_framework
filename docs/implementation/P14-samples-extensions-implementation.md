# P14 raw samples and registered extensions integration

Promoted independently reviewed isolated drafts into the live public include tree. Exact raw sample scope and tests are documented in [producer report](../../drafts/P14-samples/report.md) and [independent verification](P14-raw-samples-verification.md). Extension contracts and developer evidence are in [producer report](../../drafts/P14-extensions/report.md); final independent live evidence belongs in [extension verification](P14-extensions-verification.md).

New headers: `codec/general_samples.hpp` and `codec/extensions.hpp`. New developer/verifier test pairs are registered in P14 CMake. No existing runtime pools, state histories, device permissions or reference memory allocations are expanded. Extension registry storage is explicit caller-owned bounded storage; callbacks, immutable wire and registry must outlive validated borrows. Registration freezes; validation is pure; semantic dispatch requires authorization/admission on each call. Unknown classes remain opaque and cannot dispatch.

A verifier-found draft defect was repaired before promotion: encode validation now sees the same complete checked EnvelopeView as receive validation, rather than an empty wire span. All framework preflight errors leave output unchanged; errors once a registered encoder/validator callback runs may leave partial output as explicitly documented. Registered callbacks are trusted and must honor work/no-allocation contracts; this is not a sandbox or automatic transaction-engine integration.

The shared `wire.hpp` CAM reserved-bit mask now rejects bit0 for extension Commands while allowing the explicitly permitted bits7..1. Permissions8.6-2/3 supply this rule. The registered interface already enforced it; applying it to common envelope encode/decode avoids inconsistent direct/registered behavior. Standard Command masks remain unchanged. No interpretation I1–I12 was replaced.

Final full live gates PASS:174/174 optimized,171/171 ASan/UBSan,62 standalone headers. The promoted developer fixture initially expected the old permissive CAMbit0 encoder; it now asserts rejection, and the complete rebuilt gates passed. [Final source manifest](artifacts/P14-samples-extensions/manifest.json) and [optimized log](artifacts/P14-samples-extensions/test-release.log) preserve the candidate. Numerical sample conversion, CIF7 and remaining CIF1 structures are not implied by these additions. Real vendor class assignments/semantics and actual hardware qualification remain caller/deployment inputs.
